# **🗣️ディベートマスター📖**
waffle college 卒業ハッカソン　🏆Progate賞受賞
> waffle collegeでの学びの集大成として、初めて作ったwebアプリです！！
## プロジェクト概要
ディベートに自信がない人が、AIとディベートの練習をすることで、自信をつけるアプリ！！
## 使用技術
フロントエンド：**HTML/CSS**, **JavaScript**<br/>
バックエンド：**Python(Flask)**<br/>
データベース：**SQLite3**<br/>
AI : OpenAI API
### インストール手順

```
pip3 install Flask
pip3 install Flask-SQLAlchemy
pip3 install Flask-Migrate
pip install openai==0.28
python3 app.py
```

(OpenAIと接続するために `ai.py` ファイルの
`openai.organization`
`openai.api_key`
にapiキーとorganizationIDを入れてください)


### How to run this app

```
pip3 install Flask
pip3 install Flask-SQLAlchemy
pip3 install Flask-Migrate
pip install openai==0.28
python3 app.py
```

This app uses OpenAI services. Please add your API key and organization ID to the  `ai.py`  file before running the app.
